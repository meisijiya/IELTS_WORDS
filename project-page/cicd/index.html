Yasi Words CI/CD 教材

最后更新 2026-07-25

这套教材以 Yasi Words 的真实生产链路为主线：开发者执行 git push， GitHub Actions 构建镜像并推送到阿里云容器镜像服务 ACR，随后通过 SSH 在腾讯云或阿里云服务器上拉取并重启服务。 内容来自 CICD.md，每章保留可直接核对的章节编号与命令。

先看完整链路

  1. 本地提交进入 main 分支，触发 .github/workflows/deploy.yml。
  2. build-and-push job 在 GitHub 托管 runner 上构建并推送镜像。
  3. deploy job 使用 appleboy/ssh-action@v1 登录服务器。
  4. 服务器拉取 ACR 的 :latest 镜像，并执行 docker compose up -d。
  5. 浏览器最终访问部署后的 Next.js 服务，PostgreSQL 数据保留在持久化 volume 中。

项目首页提供了部署流程的视觉入口，见 首页的部署与 CI/CD 图示。完整原始拓扑见来源 §0。
