密码生成

三种方式产生强密码（任选其一）：

openssl rand -base64 48 | tr -d '/+='
openssl rand -hex 32
head -c 24 /dev/urandom | base64
用法：把输出塞到 /opt/yasi-words/.env 的 POSTGRES_PASSWORD / ADMIN_PASSWORD / SESSION_SECRET。详见 CICD.md §1.3。

GitHub repo secrets

用 gh CLI 写 secrets（要先 gh auth login）：

# 单条设置
gh secret set ALIYUN_REGISTRY --body "crpi-***.cn-shenzhen.personal.cr.aliyuncs.com"

# 列出当前所有 secret
gh secret list

Workflow 控制

# 强制重 build（带 fresh cache）
gh workflow run deploy.yml

# 取消正在跑的 workflow
gh run cancel <id>

想看 run 详细日志： 

gh run list --limit 5
gh run view <id> --log

ACR API 镜像列表

# 用 docker login 拿 token
docker login $ALIYUN_REGISTRY -u $ALIYUN_REGISTRY_USERNAME -p $ALIYUN_REGISTRY_PASSWORD

# 用 registry v2 API 拉 tag 列表
curl -s "https://$ALIYUN_REGISTRY/v2/meisijiya/yasi-words/tags/list" \
  -u "$ALIYUN_REGISTRY_USERNAME:$ALIYUN_REGISTRY_PASSWORD" | jq .

上面命令里的 $ALIYUN_REGISTRY / $ALIYUN_REGISTRY_USERNAME / $ALIYUN_REGISTRY_PASSWORD 都来自 server 上的 /opt/yasi-words/.env，或 GH Actions secrets 同名变量。 不要把密码 commit 到 git 或 echo 到聊天里。
